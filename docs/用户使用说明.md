# KnowledgeTree 0.1.1 使用说明

## 新用户

1. 运行 0.1.1 Windows 安装包，安装并打开 Knowledge Tree。
2. 欢迎页选择“创建新知识库”。推荐存储在文档目录下的 `KnowledgeTree`，也可选择自己的位置。
3. 点击“选择文件夹”，选择空目录；或输入准备创建的新目录路径。
4. 点击“验证并进入”。已有文件的非空目录不会被覆盖。
5. 创建第一个学科，再添加阶段、知识节点与笔记。

已有知识库选择“打开已有知识库”，选择包含各学科文件夹的根目录。打开会验证数据，不移动原文件，不清空 Git 历史。格式异常会明确提示，禁止强行初始化。

## 0.1.0 老用户

1. 在旧程序中保存正文及属性，关闭所有 KnowledgeTree 程序。
2. 建议先手工复制完整知识库（包括隐藏 `.git` 和附件）到独立位置。
3. 运行 0.1.1 安装包；以后安装新版使用相同安装方式及位置。
4. 首次进入新版会识别有效的 `<legacy-library>`，原地接入，不需要重新选择或移动数据。
5. 原库在其他位置时选择“打开已有知识库”；如果原来用环境变量指定路径，保持该变量仍可继续使用。
6. 旧主题、布局与工作区偏好在接入固定旧库时导入。0.1.0 未保存应用级最近学科，因此首次升级可能仍需选择一次学科；0.1.1 以后会恢复最近工作区。

## 管理知识库

底部“设置”可查看当前版本、知识库位置和配置目录。切换知识库前自动保存，失败会停止切换。不同知识库的同名节点不会共享草稿。

“创建完整备份”会保存知识文件、附件、Git 历史和设置并进行校验。成功后显示备份位置，请将重要备份复制到另一块磁盘。备份失败时原库不会被删除。

属性草稿出现恢复提示时，检查后选择使用草稿或保留磁盘内容；未解决的草稿冲突会阻止更新安装。

## 软件更新

当前个人版本没有在线发布源，设置会显示“尚未配置发布源”。可以继续离线使用，通过新版安装包手动更新，不需要重新选择知识库。

将来启用在线更新后：设置 → 检查更新 → 查看版本与说明 → 下载更新 → 安装并重启 → 确认保存并安装。软件先保存编辑并验证完整备份；失败则停止安装。更新包通过签名验证才允许安装。

网络不可用时可正常使用本地知识。安装失败可重新运行安装包恢复程序，不要删除知识库或用“创建新知识库”覆盖原目录。

## 常见问题

- 提示另一个实例：关闭旧版及其他 KnowledgeTree 程序后重试，不要删除锁文件来绕过保护。
- 路径不存在：检查磁盘或目录是否仍在原位置；重新连接原库，不要盲目新建。
- 环境变量指定目录：移除 `KNOWLEDGE_TREE_LIBRARY` 并重新启动后，才能在界面切换路径。
- 格式版本不支持：使用支持该版本的程序；保留所有原文件，不删除版本字段来强行打开。
- 配置损坏：保留配置文件与 `config.previous`，修复或恢复后重启，不要删除真实知识库。
