## 未执行及限制

1. `check-installer-upgrade.cjs` 安全预检发现已有 `HKCU\Software\knowledgetree\Knowledge Tree` 设置，停止于预检，未执行安装器，未修改注册表。全新安装与 0.1.0 覆盖安装必须在干净 Windows 用户/虚拟机继续验收。
2. 未配置生产 HTTPS 地址和正式密钥，没有生成可用于生产分发的签名更新包，也没有执行完整下载→安装→重启更新或安装失败恢复测试。普通本地安装包可以生成；生产更新必须通过 `release-windows.ps1 -PublishUpdate` 的签名校验前置条件。
3. 当前没有 Windows Authenticode 证书，安装包与 EXE 为 NotSigned；这与必需的 Updater 签名机制不同。
4. GNU Debug 桌面单元测试程序出现 `0xc0000139` 动态库入口加载错误。Release 测试与实际 Release 程序通过。本机未安装 MSVC linker；发布脚本使用已安装 GNU 工具链并执行 Release 测试，不能宣称 Debug 桌面测试已通过。
5. 0.1.0 不遵守新锁。已知旧进程可检测并拒绝写入，但重命名旧程序、启动竞态及外部编辑无法由普通锁完全阻止。
6. 0.1.1 没有需要执行的 Schema 2 转换。未知未来格式拒绝写入，未来破坏性迁移仍需专门实现并测试，不能把兼容读取算作已实现任意迁移。
7. 原单文件替换仍不是多文件事务；不宣称系统断电下所有编辑自动回滚。备份验证也要求外部工具在备份/迁移时停止写入。
