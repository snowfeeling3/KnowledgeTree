# Markdown 学习工作区：参考项目与实现

日期：2026-10-13。范围为前端开发态，不改变本地文档存储格式。

## 产品目标

以 Markdown 笔记本体为中心，知识图作为阅读的导航与上下文。进入学科后恢复上次笔记；没有已选笔记时打开根知识点。大纲、树图、标题目录与时间线按需展开。大纲/树图可在应用内单独最大化；正文支持专注模式，结束后还原组合布局。这里的“单独查看”是工作区内的独立区域，不是新建 Windows 原生窗口。

## 已阅读的上游与采用方式

| 项目 | 上游资料确认的能力 | 本项目的落地选择 |
| --- | --- | --- |
| [MarkText](https://github.com/marktext/marktext) | Markdown 实时预览、源码/专注模式、CommonMark/GFM | 阅读、源码、对照三种正文模式；专注正文保留还原入口 |
| [Zettlr](https://github.com/Zettlr/Zettlr) | 文本优先、全文检索、Zettelkasten 知识管理 | 将搜索与知识层级作为辅助导航，保留当前文档与区域偏好 |
| [Milkdown](https://github.com/Milkdown/milkdown) | 基于 ProseMirror 与 remark 的插件化所见即所得编辑器 | 借鉴文档编辑与功能插件分离的架构；本轮没有移植 Milkdown，也不声称实现所见即所得编辑 |
| [react-markdown](https://github.com/remarkjs/react-markdown) | Markdown AST 到 React 组件、组件覆盖、默认安全 URL 策略与 GFM 插件扩展 | 实际接入 react-markdown + remark-gfm，替换正文中的 HTML 字符串注入；支持表格、任务列表与代码块 |

资料来源是上游 README 与公开使用说明；本轮未完整审计以上项目源码。

## 已实现

- 持续存在的正文主区域；旧右侧临时正文不再覆盖知识图。
- 大纲与知识树分别展开/收起、应用内最大化与还原，保留彼此开关和宽度。
- 大纲按阶段顺序整理层级，展开控件与节点同行；打开节点立即读取 Markdown。
- 标题目录由 remark AST 提取，支持 ATX 和 Setext 标题，忽略代码块中的伪标题；跳转到相应段落。
- 源码与预览对照、Markdown 格式插入工具、关联知识点链接。链接使用 `[标题](knowledge:节点ID)`；以真实节点 ID 定位，不依赖标题唯一性。
- 知识属性、子知识与关系折叠到正文末尾，不抢占阅读空间。
- 保留 DocumentSaveQueue 与本地草稿机制；布局变化不重新创建文档会话。
- 支持键盘调整大纲/知识树宽度与 Escape 退出独立区域；新偏好可兼容旧数据。
- Markdown 模块动态加载，生产主包约 376KB，正文模块约 164KB；离线运行不依赖远程字体或渲染服务。

## 验证

- TypeScript/Vite 生产构建通过，无大包警告。
- 54 项 Vitest 测试通过，其中新增正文目录、GFM、安全渲染、格式插入与旧偏好迁移测试。
- 浏览器验收：默认正文、树图独立查看与还原、大纲最大化与还原、标题跳转、源码修改同步预览与目录、模拟写入失败保留草稿并 Ctrl+S 重试、区域宽度键盘调整、刷新恢复区域设置。
- 375 / 768 / 1024 / 1440px 未发现页面横向溢出；未捕获页面异常。
- 浏览器使用隔离内存知识库，不改动真实文档。桌面文件保存和原生窗口链路未在此次重新验收；EXE/安装包未重新构建。
- 截图与 JSON：`artifacts/study-workspace/`；自动验收：`scripts/check-study-workspace.cjs`。

## 后续学习功能方向

1. 富文本编辑：评估 Milkdown 与源码互切的格式保真、IME 输入、表格/图片、撤销栈、草稿恢复，再决定接入范围。
2. 学习编排：为知识点分离“前置知识 / 发展演化 / 延伸阅读”，以明确的先修路径指导阅读，保留人工调整。
3. 复习：按笔记记录问题、学习状态与回顾时间，避免仅用图的位置表达进度。
4. 图导航：围绕当前 Markdown 聚焦其前置与相关知识；图的视觉布局与知识本体保持独立。
